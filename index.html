Mini Project

One problem statement, take it home, build it, send back your solution.

Sales Register for a Local Kirana Store

Scenario: A neighbourhood kirana store owner wants a simple command-line tool to track daily sales instead of a paper notebook. You're building version one.

What it must do

  • Store the shop's product catalog in a dictionary: product name mapped to price.
  • Let the owner "sell" items by typing a product name and quantity, in a loop, until they type done.
  • Use a function calculate_bill(cart, tax_percent=5) that accepts everything sold and returns the subtotal, tax amount, and grand total.
  • Use a decorator @log_transaction that prints a timestamp every time a sale is finalised.
  • If the owner types a product name that isn't in the catalog, catch that with try/except and ask again instead of crashing.
  • At the end of the day, print a summary: total revenue, best-selling item, and number of transactions.

Constraints

  • Minimum 5 separate functions, each with a clear single job.
  • At least one function must use *args or **kwargs.
  • No hard-coded prices inside your functions, everything should come from the catalog dictionary.

Bonus (optional, for extra credit)

  • Save each day's transactions to a text file using what you'll learn in Module 7.
  • Add a low-stock warning if a product's remaining quantity drops below 5.
Deliverable: one .py file, well commented, plus a two-line note on one design decision you made and why. Submit through the same channel as your assignment.
